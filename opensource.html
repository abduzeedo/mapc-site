Open source

MaPC itself is proprietary software. It downloads and runs open-source software, each under its own license, which this agreement does not change.

What MaPC runs

  • Wine — LGPL 2.1 or later. The DirectX 12 engine is built from CodeWeavers’ published CrossOver source (also LGPL).
  • DXVK — zlib license.
  • MoltenVK — Apache 2.0.
  • Wine Mono — a mix of MIT, LGPL and GPL components.
  • Legendary (Epic Games) and gogdl (GOG) — GPL 3.0. They run as separate programs, and MaPC doesn’t include or change their code.

The full list, with licenses, is in the app under Settings › About › Acknowledgements, and each engine carries its own license files.

Source code

We publish the source of every engine we build with each release on the releases page. You may modify and replace these components, and you can get their source code. If you can’t find something, email support@mapc.games and we’ll send it.

Apple’s D3DMetal

D3DMetal is part of Apple’s Game Porting Toolkit. Apple’s license allows redistribution only for non-commercial use, so MaPC never includes it. You download it from Apple, and MaPC copies it after checking Apple’s signature.
