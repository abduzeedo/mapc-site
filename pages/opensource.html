Open source

The part of MaPC that runs your games is open source. The app around it (its interface and licensing) is proprietary. MaPC also downloads and runs other open-source software, each under its own license.

MaPC’s game code

Everything that decides how a game runs is open source under the Apache License 2.0: github.com/abduzeedo/mapc-engine. That covers the Wine engines and how they’re built, the graphics backends (DXVK, WineD3D), the environment each game gets, the Steam, Epic, GOG, Ubisoft and EA integrations, saves, and controllers.

If a game doesn’t work, the fix is usually there: a DLL override, an environment variable, a backend choice. You can change it, try it on your own Mac with the included mapc command-line tool, and send a pull request. MaPC uses an exact, tagged release of it.

What MaPC runs

  • Wine — LGPL 2.1 or later. The DirectX 12 engine is built from CodeWeavers’ published CrossOver source (also LGPL).
  • DXVK — zlib license.
  • DXMT (32-bit DirectX 10/11 on Metal, in the extended engine) — MIT license (version 0.80).
  • MoltenVK — Apache 2.0.
  • Wine Mono — a mix of MIT, LGPL, GPL (with an exception), MS-PL and zlib components.
  • Legendary (Epic Games), gogdl (GOG) and Nile (Amazon Games) — GPL 3.0. They run as separate programs, and MaPC doesn’t include or change their code.

The full list, with licenses, is in the app under Settings › About › Acknowledgements. Each engine carries the full license text of everything inside it, with a list of components in licenses/THIRD-PARTY-NOTICES.md. Engines don’t contain any software from Apple, and no GStreamer or video codecs: for game videos you can install GStreamer yourself.

Source code

Every engine is published on the releases page with its sources:

  • DirectX 12 engine (2.x): Wine built by us, unmodified, from CodeWeavers’ CrossOver 26.3.0 source. The exact source tarball and our build script are attached to the engine’s release, and the build script is also inside the engine (licenses/build).
  • Main engine (1.x): Wine Staging 11.18, Wine Mono 11.3.0 and DXVK as built by Gcenx. The exact sources are attached to the engine’s release: Wine 11.18, the Wine Staging patches, Gcenx’s build recipe and extra patch, Wine Mono’s source and DXVK’s source.
  • Runtime libraries (GnuTLS, FreeType, SDL2, MoltenVK and others) in both engines come from Gcenx’s Wine 11.18 builds.

You may modify and replace these components. For at least three years after we last distribute an engine, anyone who has it can ask for the complete corresponding source of any LGPL or GPL component in it, for no more than the cost of providing it: email {{EMAIL}}.

Apple’s D3DMetal

D3DMetal is part of Apple’s Game Porting Toolkit. Apple’s license allows redistribution only for non-commercial use, so MaPC never includes or distributes it. You download the toolkit from Apple under Apple’s license, which covers developing, testing and evaluating games, and MaPC copies D3DMetal from your download after checking Apple’s signature. Your use of it is governed by that license. See DirectX 12 setup.
